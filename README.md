# HR Analytics Dashboard

This repository contains a Tableau-based HR Analytics Dashboard and the corresponding dataset used for visualization. The dashboard provides insights into various HR metrics, such as employee attrition, department-wise statistics, age distribution, education field, job satisfaction, and more.

## Features of the Dashboard

- **Key Metrics:**
  - Total employee count
  - Attrition count and rate
  - Active employees
  - Average age of employees

- **Department-Wise Attrition:**
  - Breakdown of attrition across HR, R&D, and Sales departments.

- **Age Group Distribution:**
  - Number of employees categorized by age brackets.

- **Education Field-Wise Attrition:**
  - Insights into attrition across education fields like Life Sciences, Medical, Marketing, and Technical degrees.

- **Attrition by Gender and Age Groups:**
  - Gender-specific attrition rates for different age categories.

- **Job Satisfaction Rating:**
  - Job satisfaction levels segmented by job roles.

## Dataset

The dataset used for the dashboard is included in this repository as `HR Data.xlsx`. It contains anonymized employee data with the following columns:

- Employee ID
- Age
- Department
- Job Role
- Gender
- Education Field
- Attrition Status
- Job Satisfaction Rating
- Other HR-related metrics


## How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/your-repo/hr-analytics-dashboard.git
   ```
2. Open `HR Data.xlsx` in your preferred spreadsheet editor to explore the data.
3. Open the Tableau file or import the dataset into Tableau to view or modify the dashboard.
